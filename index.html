Mesa dos jogadores

Os jogadores abrem um link que mostra este mapa ao vivo: só o que a névoa revelou, sem segredos nem notas do mestre.

A transmissão precisa da sua conta conectada. Abra o Atlas pelo claude.ai para ativá-la.

  1. No menu Compartilhar, convide cada jogador como Editor. O mesmo convite vale para o mapa e para as fichas.
  2. Escolha abaixo a campanha desta mesa. Os jogadores dela entram pelo botão Mapa; o link acima também funciona.
  3. Use a ferramenta Névoa para revelar o mapa durante a sessão; tokens e mudanças aparecem para eles em segundos.

Os jogadores da campanha escolhida veem este mapa ao clicar em Mapa.
